# geno-kaggle

Kaggle benchmarking toolkit for AI coding agents -- create, run, monitor, and review benchmark notebooks on the Kaggle platform, and scrape competition discussions for insights.

## Skills

| Skill | Description |
|-------|-------------|
| `/geno-create-benchmark-kaggle` | Create a self-contained benchmark notebook for Kaggle |
| `/geno-kaggle-benchmarks-task-generate` | Scaffold a new benchmark task folder structure |
| `/geno-kaggle-benchmarks-task-review` | Pull and review results from a Kaggle benchmark run |
| `/geno-run-kaggle-bench` | Push, run, monitor, and debug a notebook on Kaggle |
| `/geno-upload-kaggle` | Upload a notebook to Kaggle |
| `/geno-kaggle-discussion` | Scrape competition discussions and generate insights |
